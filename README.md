# 🩺 Diabetes Prediction App

## Overview

This project predicts whether a patient is likely to have **diabetes** using a **Random Forest Classifier**. The model is deployed as an interactive web application using **Streamlit**.

## Features

- Age
- Hypertension
- Heart Disease
- BMI
- HbA1c Level
- Blood Glucose Level
- Gender
- Smoking History

## Model

- **Random Forest Classifier**
- Model and scaler are saved using **Joblib**.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## Run the Application

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
